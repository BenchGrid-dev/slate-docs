# SlateOS documentation

SlateOS is an open-source Linux desktop built on NixOS. Describe a task in plain language, then keep using your desktop while your agent works with its own keyboard, pointer, and workspace.

[Get started](/guides/getting-started) · [Use Slash on Linux or macOS](/guides/slash) · [Latest release](https://github.com/BenchGrid-dev/slate/releases/latest)
