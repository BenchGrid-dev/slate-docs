# SlateOS documentation

SlateOS is an open-source Linux desktop built on NixOS. It gives your agent its own keyboard, pointer, and workspace while you keep using yours. Start with Slash, the conversational shell, or try the full desktop in a virtual machine.

- [Get started with SlateOS](https://github.com/BenchGrid-dev/slate#getting-started)
- [Read the latest release notes](https://github.com/BenchGrid-dev/slate/releases/latest)
- [Contribute to SlateOS](https://github.com/BenchGrid-dev/slate/blob/main/CONTRIBUTING.md)
